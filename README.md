## Brug dataene i et projekt

[software.json](software.json) indeholder det samme katalog som strukturerede data. Find værktøjerne i `tools`, brug `id` som stabil nøgle, og slå kategorinavne op via `categoryIds` og `categories`.

## Opdatér kataloget

1. Tilføj eller ret en post i [software.json](software.json). Brug et unikt id, en dansk beskrivelse, et officielt link og mindst én eksisterende kategori. Brug `in-use` for bekræftet lokal brug og `recommended` for anbefalinger. Vælg `desktop`, `web` eller `plugin` som type.
2. Kør `python scripts/catalog.py` fra repoets rod med Python 3.10 eller nyere for at regenerere katalogsektionen.
3. Kør `python scripts/catalog.py --check` for at kontrollere data og README før commit.
